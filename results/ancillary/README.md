# Ancillary aggregate results

`three_source_full.tsv` records the held-out La Trobe, SBCSAE, and GCSAusE
comparison between the two-source and three-source full fine-tunes. Values are
fractions rather than percentages.

`crisper2_adaptation.tsv` records the manuscript's frozen source-corpus scoring
run for base and two-source-adapted CrisperWhisper2. It contains aggregate
metrics only. Restricted model outputs and weights are not redistributed.

Neither experiment adds a system to the final 100-clip CoANZSE evaluation.

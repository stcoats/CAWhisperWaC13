# CA-Whisper: anonymous review artifact

This repository accompanies an anonymous workshop submission on
conversation-analysis-informed verbatim ASR for Australian and New Zealand
web speech.

The experiments adapt `openai/whisper-large-v3` using carefully segmented
conversational speech. The principal systems are:

- a verbatim-only full fine-tune;
- a dual-policy LoRA model controlled by `<|ovw_verbatim|>` and
  `<|ovw_intended|>` decoder-prefix tokens.

The artifact contains the complete preparation, training, inference, scoring,
and paper-analysis code. It also contains a sanitized manifest and frozen
predictions for the openly implemented systems. It deliberately excludes
source-corpus audio/transcripts, model checkpoints, credentials, cluster logs,
private storage paths, and restricted CrisperWhisper outputs.

## Repository layout

- `scripts/data/`: transcript preparation, exact-boundary manifest creation,
  dual-policy target construction, and release sanitization.
- `scripts/train/`: one trainer supporting LoRA or full fine-tuning and dual
  or verbatim-only supervision.
- `scripts/evaluate/`: deterministic generation, loop protection, event
  metrics, and the clustered bootstrap analysis.
- `scripts/scoring/`: the frozen orthographic and interactional scoring policy.
- `slurm/`: portable four-GPU Slurm templates.
- `results/`: frozen aggregate results, sanitized benchmark metadata, and
  releasable prediction files.
- `docs/`: corpus reconstruction, licensing, and reproducibility notes.

## Reproduce the released CoANZSE analysis

From the repository root:

```bash
python scripts/evaluate/analyze_coanzse_results.py
```

This performs 20,000 paired bootstrap replicates clustered by source video and
writes `analysis_statistics.json`. The aggregate CrisperWhisper2 numbers remain
available in `results/coanzse_gold_v1/report.json`, but restricted model outputs
are not redistributed and therefore are not regenerated by this command.

## Run the unit tests

```bash
python -m unittest discover -s tests -p 'test_*.py'
```

## Training

First obtain the source corpora under their own terms and use the preparation
scripts to create mono 16-kHz PCM WAV clips plus a JSONL manifest. Then build
the paired-policy manifest:

```bash
python scripts/data/build_dual_policy_manifest.py \
  --source-manifest /path/to/exact_nonoverlap.jsonl \
  --output-dir /path/to/dual_policy_manifest
```

The exact full-fine-tuning and LoRA settings are recorded in `configs/`.
Portable four-GPU launch examples are in `slurm/`.
